## 四、检测策略（颜色优先 + 模板兜底）

```
每帧流程：
1. 按洞口 ROI 逐洞检测（9 个小区域，而不是全图匹配 → 快）
2. HSV 颜色分类：
   ├─ 黑色+橙红核心      → 源石虫类（尺寸区分 ·a / 普通）→ 点击
   ├─ 绿色圆形           → 西瓜/卷心菜（同判定点击，+5 无需细分）→ 点击
   ├─ 蓝白机械           → 无人机 → 优先点击
   ├─ 冰蓝色             → 冰爆源石虫 → 跳过该洞
   ├─ 紫色               → 异质源石虫 → 跳过该洞
   └─ 超大+强红光/橙红核心大面积 → 巨型变异源石虫 → 连点
3. 全屏红色占比 > 阈值 → WARNING Boss 事件 → 对核心坐标连点
4. 点击节流：同洞冷却 ~100ms，避免误点刚消灭的洞
```

HSV 参考（待实机调参）：
- 源石虫核心橙红：H 0-20°, S 高, V 高
- 西瓜绿：H 35-85°；卷心菜浅绿：H 35-85° 低 S
- 无人机蓝白：H 190-230° 低 S 或高 V 低 S
- 冰爆冰蓝：H 180-210°, V 很高（⚠️ 与无人机接近，需模板二次确认）
- 异质紫：H 250-290°
- Boss 核心：H 0-20°, S 很高, V 很高，面积远超普通洞
